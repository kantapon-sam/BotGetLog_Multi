# Version 1.2.11

Juniper collection now produces LLDP and physical port capacity reports alongside CPU/Memory using the existing command set. Neighbor rows preserve core hostnames, physical port counts do not multiply when several neighbors share a port, active ports are counted as used even without a description, and explicit AE bundle membership is exported. CPU/Memory uses the Master Routing Engine with a consistent node identity across reports. Unknown measurements remain blank.

Collection validation accepts Junos combined quit/close lines and shortened command redraws. ZTE LACP and LLDP commands may return an empty table after a verified prompt. Required commands, nonempty mandatory measurements, device identity, and session-recovery checks remain enforced. Existing logs and historical failure events are preserved.

Validation: 19 regression suites pass on Windows and server Java 8; 253 production transcript replays; all eight Juniper captures exported with 1,478 physical ports, 703 neighbors and eight CPU/Memory rows. Five report outputs from Nokia, Huawei and ZTE fixtures remain identical to the preceding release. Four fresh live collections (two Juniper and two ZTE) pass both transcript validation and collector session checks. Windows installation from v1.2.10 verifies the updater preserves user inventory, credentials, preferences and logs. True Logs runtime compatibility also passes.

The current Juniper commands contain the data required for these three reports. Optional `show version` output is understood for software/chassis model fields; those fields remain blank when that command was not collected. Free capacity covers physical interfaces present in the log at the existing 1G/10G/100G report speeds; it does not infer unreported chassis slots. Physical `ge-` and `xe-` interfaces identify 1G and 10G capacity respectively; `et-` requires an explicit 100G speed to enter the 100G total. Unknown, 40G and 400G `et-` speeds are not counted as 100G. Logical units and aggregate interfaces are excluded from physical capacity.
